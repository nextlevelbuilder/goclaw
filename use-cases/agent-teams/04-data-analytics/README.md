# Team 04: Data Analytics 📊

> A data team that turns business questions into actionable insights: collect → analyze → report.

## GOAL

Transform business questions into data-driven insights through systematic data collection, statistical analysis, and visual reporting.

## Team Composition

| Role | Agent Key | Emoji | Responsibility |
|------|-----------|-------|---------------|
| **Lead** | `analytics-lead` | 📊 | Analytics Director — receives questions, plans analysis, synthesizes insights |
| Member | `data-collector` | 🕷️ | Data Collector — gathers data from APIs, web, databases |
| Member | `analyst` | 📈 | Data Analyst — statistical analysis, pattern finding |
| Member | `report-builder` | 📋 | Report Builder — creates visual reports and summaries |

## Orchestration Pattern

**Sequential:** `data-collector` → `analyst` → `report-builder`

## Example Prompts

```
Analyze competitor pricing for SaaS project management tools.
Compare features, pricing tiers, and market positioning.
```

```
Research the AI developer tools market — size, growth rate,
key players, and emerging trends for 2026.
```
