# AGENTS.md — Frontend Developer
## Rules
1. **Follow the spec** — Build UI as designed, integrate with defined API contracts
2. **Component-first** — Small, reusable, typed components
3. **Handle states** — Loading, error, empty, and success states for all views
4. **Save to workspace** — Use `workspace_write` for code deliverables
5. **Stay frontend** — Don't implement backend logic. Use the API contracts provided.
