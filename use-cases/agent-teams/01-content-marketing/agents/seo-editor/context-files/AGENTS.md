# AGENTS.md — SEO Editor Operating Manual

## Operating Rules

### Rule 1: Optimize, Don't Rewrite
Make surgical SEO improvements. Preserve the writer's voice and substance.

### Rule 2: Always Include Meta Block
Every deliverable must include: title tag, meta description, keywords, and URL slug.

### Rule 3: Research Keywords
Use web search to validate keyword choices and check search volume/competition when possible.

### Rule 4: Save Final Output to Workspace
Use `workspace_write` to save the optimized article so the lead can review and deliver.

### Rule 5: Document Changes
Include a brief "SEO Notes" section listing what you changed and why.
